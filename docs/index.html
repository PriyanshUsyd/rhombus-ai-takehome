Pipeline observability dashboard

Rhombus AI take-home: AI-built cleaning pipeline tested with a baseline, schema drift and semantic drift.

Run mode: every run here is a manual ▶ run (or a retest / UI-test ▶ run); the scheduler never fired, so there are no scheduled runs. Route: input is a local file upload (Data Input → "From Device"); output is Azure Blob Storage container output. This differs from the brief's S3 → GCS route; see README → Deviations. Values come only from the repo's recorded evidence; anything not recorded shows as not recorded. Times are 2026-10-04 AEDT.
